# Etiquetas · pegatinas (etiquetas.jpg)

Elegida la opción «pegatinas». Sustituye al estilo actual (.tag, tipo Notion).

- Letra Gochi Hand, siempre con «#» delante (el # con opacidad .55).
- Fondo de color suave, texto oscuro del mismo tono, esquinas algo irregulares (4px 7px 5px 8px).
- Un poco torcidas (entre -2° y 2°). El giro sale del nombre (hash), así cada etiqueta sale siempre igual.
- Sombra corta abajo: 0 2px 0 rgba(22,24,58,.12); sobre el fondo de la tanda, .35.
- Tamaños: pequeña (16px, en listas, apuntes y tanda) y normal (19px, filtro y editor).
- Elegida en el editor: borde de 2px del acento alrededor.

## Paleta (fondo / texto)
| color | fondo | texto |
|---|---|---|
| lavanda | #E6E1FB | #3B2E8F |
| rosa | #FBE1EE | #7A1F4F |
| limón | #FFF3B8 | #5E4B00 |
| salvia | #E2EDD6 | #2F4A1C |
| agua | #D6F0F1 | #0F4E52 |
| arena | #F1E8DC | #5A4330 |
| gris | #ECEDF3 | #3A3F55 |

Los colores antiguos de las etiquetas se pasan al más parecido (purple→lavanda, pink/red→rosa,
yellow/orange→limón, green→salvia, blue→agua, brown→arena, gray/default→gris). En oscuro: mismo texto
claro sobre una versión oscura del fondo.

## Dónde salen
Tanda (arriba de la pregunta), filas de la lista, propiedades del apunte, filtro de Biblioteca (en vez de las
píldoras actuales) y selector del editor (buscar o crear + colores).

## Gestionar etiquetas
Lista con la pegatina, cuántas preguntas la llevan, los 7 colores, Renombrar y Borrar (las preguntas se
quedan, solo pierden la etiqueta). Abajo, «Nueva etiqueta» + Crear.
